## 📌 专题笔记：三维数组索引（W2 第 11 题踩的坑）

### 问题的来源

小测第 11 题：`arr.shape = (2, 2, 3)`，问 `arr[0, 1]` 和 `arr[:, :, 1]` 各得到什么。
**这是 W2 最抽象的概念**，也是任务 3 向量化灰度化的直接前提。

### 核心规律（记住这一条就够）

> **写几个具体数字，就塌掉几个维度；`:` 表示"这一维全都要"，不塌。**

| 写法 | 具体数字个数 | 结果形状 | 含义 |
| --- | --- | --- | --- |
| `arr[0, 1, 2]` | 3 | 0 维（一个数） | 某行、某列、某通道的**一个数值** |
| `arr[0, 1]` | 2 | `(3,)` | **一个像素**的 RGB 三个值 |
| `arr[0]` / `arr[:, 1]` | 1 | `(4, 3)` / `(3, 3)` | 一整行 / 一整列（含所有通道） |
| `arr[:, :, 1]` | 1 | `(3, 4)` | **整张绿色通道图**（二维） |
| `arr[:, :, :]` | 0 | `(3, 4, 3)` | 原图，什么都没变 |

### 省略的写法（容易误判）

- `arr[0]` **等价于** `arr[0, :, :]` —— 省略的下标默认是 `:`，**不是"全保留"**
- `arr[:, 1]` **等价于** `arr[:, 1, :]` → 得到 `(3, 3)`，不是 `(3, 4, 3)`

### 图像数组的三个维度

```
arr.shape = (高, 宽, 通道)        例如 (480, 640, 3)

arr[y, x, c]
    ↑  ↑  ↑
   行  列  通道 (0=红, 1=绿, 2=蓝)
```

⚠️ **和 PIL 的顺序不同**：
- PIL：`img.size = (宽, 高)`，取像素是 `px[x, y]`
- NumPy：`arr.shape = (高, 宽, 通道)`，取元素是 `arr[y, x, c]`

### 跟任务 3 的关系（为什么必须搞懂）

向量化灰度化的三步：

```python
arr = np.array(img)                 # (高, 宽, 3)
r = arr[:, :, 0]                    # 整张红色图 (高, 宽)
g = arr[:, :, 1]                    # 整张绿色图 (高, 宽)
b = arr[:, :, 2]                    # 整张蓝色图 (高, 宽)
y = 0.299*r + 0.587*g + 0.114*b     # 三个二维图逐元素加权 → 一张灰度图 (高, 宽)
```

**这三行能读懂的关键，就是上面的"塌陷规律"。**

### 自测（不看答案先答）

1. `arr = np.zeros((5, 8, 3))`，`arr[2].shape` = ?
2. `arr[:, :, 0].shape` = ?
3. `arr[2, 3]` 和 `arr[2, 3, :]` 一样吗？
4. 想取"所有行的第 0 列、所有通道"，怎么写？

<details>
<summary>答案</summary>

1. `(8, 3)` —— 第 2 行，含所有列和通道
2. `(5, 8)` —— 整张红色通道图
3. **一样**，都是 `(3,)`，省略的 `:` 会自动补上
4. `arr[:, 0, :]`（或简写 `arr[:, 0]`）
</details>
