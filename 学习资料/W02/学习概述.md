## 二、四个任务包

### 📦 任务 1：NumPy 入门（2~3 小时）

**在哪练**：交互模式（`python`），不写文件。

```python
>>> import numpy as np
>>> a = np.array([[1, 2, 3], [4, 5, 6]])
>>> a.shape          # → (2, 3)   形状：2 行 3 列
>>> a[1, 2]          # → 6        取第 1 行第 2 列（一个括号，逗号分隔）
>>> a[1][2]          # → 6        也能用，但 NumPy 的习惯是上面那种
>>> a[:, 1]          # → [2 5]    所有行的第 1 列
>>> a[1, :]          # → [4 5 6]  第 1 行所有列
>>> a.sum(axis=0)    # → 按列求和
>>> a.sum(axis=1)    # → 按行求和
```

| 要掌握 | 要点 |
| --- | --- |
| `np.array(列表)` | 把 Python 列表变成数组 |
| `arr.shape` | 维度信息，**元组**形式 |
| `arr.dtype` | 元素类型（`uint8` = 0~255 无符号整数） |
| 索引 | `arr[y, x]`（一个括号、逗号分隔，**y 在前**） |
| 切片 | `arr[0:100, 0:200]`、`arr[:, 1]`、`arr[1, :]` |
| `axis` | `axis=0` 按列、`axis=1` 按行（**先记住这个，具体含义画图理解**） |

**验收**：能回答「`arr.shape` 返回 `(1080, 1920, 3)`，这三个数分别是什么？」→ **高、宽、通道**

### 📦 任务 2：图片 ⇄ NumPy 数组（1 小时）⚠️ 最容易翻车

```python
import numpy as np
from PIL import Image

img = Image.open("testdata/small_640x480.jpg")
arr = np.array(img)               # PIL 图片 → 数组
print(arr.shape)                  # 猜：(480, 640, 3) 还是 (640, 480, 3)？
```

**必须亲手验证的坑**（三种写法顺序不同）：

| 来源 | 写法 | 顺序 |
| --- | --- | --- |
| PIL 尺寸 | `img.size` → `(640, 480)` | **宽、高** |
| PIL 取像素 | `px[x, y]` | **x、y** |
| NumPy 形状 | `arr.shape` → `(480, 640, 3)` | **高、宽、通道** |
| NumPy 取元素 | `arr[y, x, c]` | **y、x、通道** |

**验收**：能解释「为什么 `np.array(img).shape[0]` 是 480 而不是 640」。

### 📦 任务 3：向量化重写灰度化（2~3 小时）★ 核心

**思维转变**：不要想"每个像素怎么算"，要想"**整张图一起算**"。

```python
import numpy as np
from PIL import Image

def to_gray_numpy(img):
    arr = np.array(img)                     # (h, w, 3)
    r = arr[:, :, 0]                        # 所有行、所有列、第 0 通道 → 红色整张图
    g = arr[:, :, 1]                        # 绿色整张图
    b = arr[:, :, 2]                        # 蓝色整张图
    y = 0.299*r + 0.587*g + 0.114*b         # ← 没有循环！三个数组一起算
    return Image.fromarray(y.astype(np.uint8))
```

| 关键写法 | 含义 |
| --- | --- |
| `arr[:, :, 0]` | 三维索引：`:` = 所有行，`:` = 所有列，`0` = 第 0 个通道 |
| `0.299 * r` | **广播**：一个数 × 整张数组 = 每个元素都乘 |
| `a + b` | **逐元素运算**（不是矩阵乘法！） |
| `.astype(np.uint8)` | 小数数组 → 整数数组；**注意：`astype` 是截断，不是四舍五入**（与循环版的 `int()` 一致，正好可以对拍） |

**验收**：向量化版与循环版**逐像素完全一致**：

```python
import numpy as np
a = np.array(to_gray(Image.open("testdata/small_640x480.jpg")))        # 循环版
b = np.array(to_gray_numpy(Image.open("testdata/small_640x480.jpg")))  # 向量化版
print(np.array_equal(a, b))     # → 必须是 True
```
